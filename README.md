
# Footylytics

Football Team Performance Analytics

Footylytics is a football analytics dashboard designed
to analyze English Premier League team performance
during the 2024/2025 season.

## Features

- Season overview: match count, total goals, goals per match, and result distribution.
- Monthly goal trends and home win/draw/away win distribution.
- League standings and goals scored versus goals conceded.
- Team performance map based on points and goal difference.
- Team analysis: match-by-match goal trends, results breakdown, and home/away points.
- Two-team statistics comparison and season highlights.

## Technology Stack

- Python
- Pandas
- Plotly
- Streamlit

## Dataset

Source: Football-Data.co.uk

Competition: English Premier League

Season: 2024/2025

## Installation

1. Clone this repository.

2. Install dependencies:

   pip install -r requirements.txt

3. Download the EPL 2024/25 dataset.

4. Place E0.csv inside the data directory.

5. Run the application:

   streamlit run app.py
